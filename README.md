# Gestor de Tareas

Aplicación de consola desarrollada en Python que permite administrar tareas mediante un menú interactivo.

## Funcionalidades

- **Listar tareas:** visualizar todas las tareas y su estado actual.
- **Agregar tareas:** incorporar nuevas tareas mediante una descripción.
- **Completar tareas:** marcar tareas como completadas.
- **Eliminar tareas:** quitar tareas de la lista.

## Tecnologías utilizadas

- Python 3

## Requisitos

- Tener Python 3 instalado.

## Cómo ejecutar el proyecto

1. Clonar el repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Entrar en la carpeta del proyecto:

   ```bash
   cd gestor-de-tareas
   ```

3. Ejecutar la aplicación:

   ```bash
   python app.py
   ```
